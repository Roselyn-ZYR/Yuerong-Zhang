# Yuerong Zhang / 作品网站

根据提供的多页作品集结构重新制作。纯静态 HTML、CSS、JavaScript，无需安装依赖；可以双击 `index.html` 查看，也支持 GitHub Pages 的仓库子路径。

## 页面

- `index.html`：封面轮播、精选作品、研究、个人介绍、教学入口和联系。
- `work.html`：全部 24 个项目，支持按媒体艺术、机器人制作、空间设计和绘画手绘筛选。
- `project.html?id=nushu`：从同一份项目数据生成详情，支持放大封面、过程图和外部视频链接。
- `gallery.html`：横向作品画廊，可滑动、使用左右方向键或箭头按钮浏览。
- `research.html`：女书与女性主义历史、机器人材料系统、具身交互。
- `about.html`：个人介绍、教育、经历及研究支持。
- `teaching.html`：课程、教学方法和 Robotic Tectonics。
- `contact.html`：学校邮箱、个人邮箱、Instagram、女书网站。
- `404.html`：找不到页面时的返回入口。

## 替换项目封面

1. 将新图片放进 `assets/images/`。推荐使用 JPG、WebP 或 PNG，宽度 1600 至 2200 像素。
2. 打开 `assets/js/projects.js`，找到对应项目。
3. 修改 `image`、`alt`、`imageCredit`，并将 `imageWidth`、`imageHeight` 更新为图片的实际像素宽高。同一个路径会用于首页轮播、作品索引、横向画廊和详情封面。

竖版封面不适合横向裁切时，加入 `"imageFit": "contain"`，首页轮播和横向画廊会在原有尺寸中完整展示图片，周围保留页面底色。Work 和详情页默认跟随原图比例。

例如，将女书项目的相关字段改为：

```js
"image": "assets/images/nushu-cover.jpg",
"imageWidth": 2200,
"imageHeight": 1467,
"alt": "女书装置在展览现场的全景",
"imageCredit": "摄影：填写实际摄影者"
```

当前 SVG 来自你提供的文件，是抽象示意图。SVG 封面会有小型 Image study 标识；替换为 JPG、PNG 或 WebP 后自动消失。图片内容说明和摄影署名也要同步更新。HEIC 没有加入网站，需先转为浏览器可用的图片格式。

课程示意图独立位于 `index.html` 和 `teaching.html`，搜索 `arches-teaching.svg` 即可找到。Hiwi 的 SoSe25 记录使用 `hiwi-sose25.jpg`，显示在 Robotic Tectonics 项目和教学页的 Student assistance 部分。

## 添加过程图和视频

在项目对象里加入 `images` 数组，即可显示额外图片；没有过程图时不会出现空白章节：

```js
"images": [
  {
    "src": "assets/images/nushu-process.jpg",
    "width": 2200,
    "height": 1467,
    "alt": "材料试验过程",
    "caption": "材料测试 / 2026"
  }
],
"links": [
  { "label": "Watch film", "url": "https://vimeo.com/你的视频编号" }
]
```

需要页内 Vimeo 播放器时，加入 `video`。`aspectRatio` 为宽除以高，竖版 3:4 填 `0.75`，省略时按 16:9 显示；外链仍保留作为独立观看入口：

```js
"video": { "vimeoId": "1127870065", "aspectRatio": 0.75 },
"credits": [
  { "role": "Structural design", "name": "Zhengyao Liu" },
  { "role": "Music composition", "name": "Yuehang Zhang" }
],
```

`credits` 的每一项会显示在详情页资料栏，可用于合作者分工或摄影署名。没有视频或合作者时可省略相应字段。

Shifts and Echoes（原名 Repetition）是 2025–2026 年兼职期间的日常声音留存，作为独立的空间音频作品加入索引，未加入首页精选。原名保留在作品说明中，原项目链接 `project.html?id=repetition` 不变。详情页播放器上方保留耳机收听提醒。网页使用完整立体声 256 kbps MP3（约 2 分 11 秒），封面由原音频的真实波形生成；原始 WAV 未修改，未作响度归一化或裁切。

添加同类音频可使用 `"audio": { "src": "assets/audio/repetition.mp3", "duration": "02:11", "listeningNote": "Please listen with headphones." }`。播放器不会自动播放，仅提供试听、进度和音量控制，不提供下载链接或原生下载菜单。使用浏览器原生音频引擎和自定义控制条，以免部分浏览器忽略隐藏下载选项的设置。

这是试听界面设置，不是文件加密或 DRM：浏览器必须接收音频才能播放，不能保证阻止保存、网络工具提取或录音。原始 WAV 仍留在原来的本地目录，未放入网站；网站只包含试听用 MP3。

Video Interference 和 Sky Tree Glitch 是 2026 年 6 月的 Processing 研究，已用本地 p5.js 1.11.11 改写为浏览器交互。两项已加入作品索引，未改变首页精选范围。标题暂沿用整理时的名称。

交互程序为 `interactive.html`、`assets/js/interactive.js` 和 `assets/css/interactive.css`。详情页通过 `interactive: { "id": "video-interference" }` 或 `interactive: { "id": "sky-tree-glitch" }` 嵌入。工具栏支持暂停、重置和保存图片。Video Interference 默认是风景素材，仅在访客主动点击 Camera 后请求摄像头，不使用麦克风、不录制、不上传；切换页面或隐藏标签时关闭摄像头。浏览器拒绝权限或无摄像头时保留图片体验。摄像头推荐通过 GitHub Pages HTTPS 或 localhost 使用；VS Code 内置文件预览可能限制摄像头。

Sky Tree Glitch 保留原作 7 张天空、22 张树木素材和字体。鼠标和触摸均可改变图像，按住切换网格；键盘方向键也可改变位置，空格暂停，回车切换网格。绘制数量和形变幅度针对浏览器做了性能与稳定性调整，并非 Java 原作的逐帧复刻。素材在 `assets/js/sketch-assets.js` 内嵌，以支持直接打开本地 HTML。原始文件未修改；脸部录屏不再包含在网站中。

网页文字使用“天空”和“树”的女书字形。原始 NyushuSerif 字体没有“木”的映射，网页依照确认改用单字“树”，避免混入系统汉字；原始 `.pde` 文件保留原样。

用 `"source": { "src": "assets/source/sky-tree-glitch.pde", "label": "Processing sketch" }` 添加原始代码下载。此处仅提供 `.pde` 文件，不是完整可运行的 Processing 项目包；Sky Tree Glitch 所需的原始 `data/sky`、`data/tree` 和字体仍在原始项目目录中。

长篇项目介绍可以加入 `sections` 数组，每一项的 `title` 是小标题、`text` 是对应正文。例如：

```js
"sections": [
  { "title": "The Suspended Sphere", "text": "在这里填写这一节的正文。" },
  { "title": "Audience Interaction", "text": "在这里填写下一节的正文。" }
],
```

`featured: true` 表示显示在首页精选区和横向画廊；封面轮播默认读取全部项目，`homeGallery: false` 可单独从首页轮播隐藏。`year` 未确认时留空。可选 `role` 填写个人分工。保留项目的 `id`，避免已有链接失效。所有字段为纯文本，不需要写 HTML。摄影署名未知时，`imageCredit` 留空，详情页不显示空的署名行。

作品统一按年份从新到旧展示：`Ongoing`、`Present`、`进行中`、`至今` 放在最前；年份范围按其中最新的四位年份排序，例如 `2019–2023` 按 2023 排序；未填写年份的项目放在最后。同一年保留项目清单中的原顺序；Work 索引的封面按原比例自然错落排列，分类筛选与精选范围保持原设置。

详情页需要学期等更具体的时间时，可加 `period`，例如 `"period": "WiSe24/25 · SoSe25"`；`year` 仍填 `2025`，用于索引与年份排序。

## 横竖图排版

- Work 封面跟随图片本身的比例完整显示，不套用统一横框，也不补灰色边框；`imageWidth`、`imageHeight` 用于加载前预留尺寸。桌面为三列，平板为两列，手机为单列；标题紧随各自封面。只有明确设置了 `coverCrop` 的项目保留指定裁切，例如 Florale Kunst-Interpretationen 的横版构图。
- 竖版封面在大屏与简介并排；平板使用居中封面加下方简介，手机端自动改为单列。
- 每张细节图填写实际 `width` 和 `height`。相邻的两张竖图自动组成等高双图；单独的竖图居中显示。
- 横图默认独占一行。想把两张横图组成一组时，两项都加 `"layout": "pair"`，并在 `images` 数组里相邻排列。
- 一张竖图需要独立呈现时，加 `"layout": "single"`，不会与下一组双图混排。Isolated Us 的 PCB 材料实验图使用这个设置。
- 图文需要在同一段出现时，可用 `documentationGroups: [{ "id": "materials", "layout": "material", "title": "标题", "text": "说明" }]`，并给相应图片加 `"group": "materials"`。`material` 为紧凑竖图与说明并排，默认分组为标题、说明和等宽双图，手机端自动单列。Isolated Us 后半段采用三个分组；图片顺序和放大功能不变。
- 分组保持数组顺序；手机端每组依次展开为单列。点击封面或细节图都可放大。
- `images` 数组的顺序就是展示顺序，可以按整体、互动、材料细节调整；这不会改变项目之间按年份排列的顺序。
- 一组三张竖图需要并列对照时，在项目上加 `"documentationColumns": 3`，手机端仍按数组顺序展开为单列。Nüshu 的 Main 为封面，细节图依次为 Question1、Q2、Q3。
- 首页精选作品每两项组成一行，按实际 `imageWidth`、`imageHeight` 分配宽度，让同一行的图片等高且完整显示。手机改为单列，仍保留原图比例；Work 独立使用原比例封面布局。
- 每张细节图可加 `question`、`answers` 字符串数组及 `captionNote`，分别显示图下问题、逐条回答和补充说明。Nüshu 的三个问题及英文回答直接对应三张瓷板图；现场照片和手机截图仅作参考，不加入网页。
- 中英对照使用 `answers: [{ "zh": "计划落空", "en": "Unfulfilled plans" }]`，每一对在同一条目中显示。可配合 `captionZh`、`questionZh`、`captionNoteZh`。Nüshu 保留原中文词组与顺序，时间为 July 2026（2026 年 7 月）。
- 可用 `"relatedProject": "echo"` 关联已有项目；详情页会显示站内链接，例如从 Nüshu 陶瓷系列返回 Subversive Echoes 表演。
