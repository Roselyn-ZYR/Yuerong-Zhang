# Yuerong Zhang / Roselyn ZYR Portfolio Template

A minimal blue static website framework for a media art portfolio. It is designed for GitHub Pages and can run without a build step.

## Edit Content

- Update `index.html` for text, links, project titles, and research descriptions.
- Replace each `.media-placeholder` block in `index.html` with an image, video, or project link when your final project visuals are ready.
- Adjust visual style in `styles.css`.

## Publish On GitHub Pages

1. Create a GitHub repository named `roselyn-zyr.github.io` or any portfolio repository.
2. Upload these files to the repository root.
3. In GitHub, open `Settings > Pages`.
4. Set source to `Deploy from a branch`.
5. Choose `main` and `/root`.

If the repository is named `roselyn-zyr.github.io`, the site will publish at `https://roselyn-zyr.github.io/`.
